How the demo works

Phone images come from manufacturer CDNs and Wikimedia Commons; if a URL fails, a stylized SVG fallback renders automatically so the catalog never shows a broken image. API calls to Pega are simulated in-browser with 600–1500 ms round-trip latency and an 8% autonomous-recovery failure rate. No server required — double-click index.html to run.
